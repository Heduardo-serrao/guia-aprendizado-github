A modelagem de dados é uma base solida para o sucesso de qualquer sistema de informação. Antes de escrever linhas de código ou instalar um gerenciador de banco de dados, é preciso planejar como as informações serão organizadas e estruturadas.
Esse processo é dividido em etapas fundamentais, onde se destacam o modelo conceitual e o modelo lógico.Eles funcionam como um projeto de uma casa, transformam as necessidades e regras do negócio em estruturas organizadas, garantindo que o banco de dados final seja eficiente, seguro e livre de erros tanto por parte do cliente com as regras de negocio tanto por parte do desenvoverdor.
